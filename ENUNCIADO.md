# Enunciado / material de partida — Liebre y Tortuga

Fuente: práctica `LiebreTortuga` conservada en Google Drive dentro del bloque de hilos de PSP.

Simular mediante dos tareas concurrentes una carrera entre una liebre y una tortuga, actualizando el progreso de ambos participantes hasta que alguno alcanza la meta. La práctica original utiliza hilos y una interfaz Swing para visualizar el avance.

La versión actual separa el motor concurrente de la interfaz, evita estado global compartido innecesario y realiza las actualizaciones visuales en el hilo de eventos de Swing.

No existe una base de datos asociada.

> Drive conserva tanto la carpeta como el ZIP del proyecto original; no se ha localizado un PDF independiente del enunciado.
